# AI Text Summarizer Demo

A simple project demonstrating how to use Hugging Face’s `transformers` library to build a text summarizer.  
This project is part of my learning journey in AI and natural language processing.

## Features
- Summarizes long text into concise key points
- Uses Hugging Face’s pre-trained models
- Easy to run in Google Colab or locally with Python
